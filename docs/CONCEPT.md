# ポップアップコンピュータ再現構想（PopupMaker.next）

> 1990年代のCD-ROM作品「ポップアップコンピューター」の"手ざわり"を、
> 2020年代のWeb技術で再構築するための構想メモ。

---

## 0. 原典について

**『Pop up Computer』**（ポップアップコンピューター）

| 項目 | 内容 | 確度 |
|---|---|---|
| 作者 | **松本弦人**（1961年生、アートディレクター／グラフィックデザイナー） | 確認済 |
| 発売元 | **アスク講談社**（1981年設立。1998年に講談社出資分を買い戻し「アスク」に、2017年アスク出版へ吸収合併） | 確認済 |
| 対応環境 | Macintosh / Windows 3.1 / Windows 95 のハイブリッド | 確認済 |
| 定価 | 4,800円 | 確認済 |
| 形態 | 「飛び出す絵本CD-ROM」を謳ったデジタル絵本 | 確認済 |
| 発売年 | 1995〜1996年頃 | **要確認** |
| 受賞 | マルチメディアグランプリ 通商産業大臣賞、という情報あり | **要確認** |

松本弦人は同時期に、デジタローグから『ジャングルパーク』、後年には任天堂の『動物番長』など、
デジタルメディアのアートディレクションを手がけている。つまり**これはゲーム会社の作品ではなく、
グラフィックデザイナーの作品**である。ここが本質で、再現の指針にもなる
（ゲーム的な設計を足すと必ず壊れる、の根拠）。

一次資料は中古市場（ヤフオク・メルカリに現物の出品あり）と、
文化庁メディア芸術データベースの「アスク講談社」項が当たれる。

### 何が良かったのか（再現すべきコア）

| 要素 | 中身 |
|---|---|
| 紙であること | 画面の中のものが全部「紙でできている」。厚みがあり、折れ、影が落ちる |
| 展開する快感 | 開くと立ち上がる。閉じると畳まれる。可逆で、何度でもやりたくなる |
| 目的がない | スコアもクリアもチュートリアルもない。触ると反応する、それだけ |
| 音が主役 | 全てのオブジェクトが固有の音を持つ。BGMではなく「効果音の楽器化」 |
| 世界が小さい | 机の上に収まるスケール感。全体を把握できる安心感 |
| コンピュータのパロディ | 「紙でできたコンピュータ」というメタな見立て |

**この6つを満たせば、絵が違っても"あれ"になる。** 逆に3D的にリッチにしたり、
達成要素を足したりした瞬間に別物になる。

## 1. 三つの方向性と選択

### 案A：保存・エミュレーション（原典を動かす）
- 現物のCD-ROMを入手 → ディスクイメージ化
- Mac版: SheepShaver / Basilisk II（Mac OS 8-9 + QuickTime）
- Win版: 86Box or PCem + Win95/98、あるいは Wine
- 中身はほぼ確実に Macromedia Director のプロジェクタ。`ProjectorRays` 等の
  Director 逆コンパイラで内部構造（キャスト、スコア、Lingo）を読める（要検証）
- **法的**: 自分で買った現物を私的に動かす／構造を調査するのは可。
  イメージやアセットの再配布・流用は不可。

→ **位置づけ：研究フェーズ。作品化ではなく「教科書」として使う。**

### 案B：クローン再制作（絵も含めてそっくりに作り直す）
- 著作権的にアウトに近く、かつ一番つまらない。**却下。**

### 案C：紙のOS（Paper Desktop）— 本命 ★
「紙でできたコンピュータ」という見立てだけを継承し、
**ポップアップ絵本そのものがデスクトップ**である作品を新規に作る。

- 見開き1ページ = 1画面。ページをめくるとアプリが切り替わる
- 時計は回転盤（ヴォルヴェル）、音楽プレイヤーはオルゴール、天気は箱庭ジオラマ
- 全部が実在しうる紙工作として成立する（＝**印刷して実際に作れる**）

→ ここに **PopupMaker**（ポップアップ機構オーサリングツール）を組み合わせる。
　　作品と、作品を作る道具を、同じエンジンで作る。

## 2. 中核となる技術アイデア：ポップアップは「1自由度の機構」である

これが本構想の技術的な背骨。

ポップアップ絵本の飛び出しは**物理シミュレーションではない**。
剛体パネル＋ヒンジのリンク機構であり、駆動パラメータは**背（スパイン）の開き角 θ ただ一つ**。

```
θ = 0 (閉)  ────────────────►  θ = π (見開き平ら)
                 ↓
   全パネルの姿勢が θ の関数として一意に決まる
```

- 4本の折り線が1点で交わる剛体折り紙頂点（degree-4 vertex）は**1自由度**であり、
  隣接する折り角どうしは球面三角法で閉形式に結ばれる
- したがって V字折り・平行折りは**解析的に解ける**。毎フレーム θ を入れれば姿勢が出る
- 複合機構やタブ駆動など解析が面倒なものは、
  Blender で作って θ をドライバにしたアニメーションを **glTF にベイク**すれば同じ扱いになる

### 実装する基本機構（MVP は上4つ）

| 機構 | 和名 | 駆動 |
|---|---|---|
| V-fold | V字折り | θ |
| Parallel fold / box | 平行折り・箱 | θ |
| Layer / step | 階段折り | θ |
| Pivot | 回転（リベット） | θ or ドラッグ |
| Pull tab | プルタブ | ドラッグ |
| Volvelle | 回転円盤 | ドラッグ |
| Slider | スライダー | ドラッグ |

### 「本当に作れるか」の検証器（Validator）
ツールとして差別化できる部分。θ を 0→π にスイープして数値チェックする。

1. **収納性**: θ=0 のとき、全パネルが見開きの外形からはみ出さないか
2. **貫通判定**: 途中の θ でパネル同士が交差しないか
3. **平坦性**: θ=0 で厚みが破綻しないか（層数の上限）
4. **糊代**: 接着面積が最低値以上あるか

NG のヒンジを赤くハイライトして、直せる範囲を提示する。

## 3. アーキテクチャ

```
┌─────────────────────────────────────────────┐
│  Next.js (App Router) / TypeScript          │
├──────────────────┬──────────────────────────┤
│  Viewer          │  Editor (PopupMaker)     │
│  React Three     │  SVG 2D 型紙ビュー       │
│  Fiber + drei    │  ＋ 3D プレビュー分割    │
├──────────────────┴──────────────────────────┤
│  popup-core (機構カーネル / 依存なし)        │
│   ・Mechanism 定義と θ→姿勢のキネマティクス  │
│   ・Validator（収納性・干渉・糊代）          │
│   ・展開図ジェネレータ（SVG）                │
├─────────────────────────────────────────────┤
│  Web Audio（θ速度に応じた紙擦れ音の粒状合成）│
└─────────────────────────────────────────────┘
```

`popup-core` を **React にも Three.js にも依存しない純粋な TS パッケージ**にするのが肝。
これで CLI からも Node からも叩けて、展開図の一括生成や回帰テストができる。

### シーン記述フォーマット（`.popup` = JSON）

```jsonc
{
  "version": 1,
  "title": "紙のデスクトップ",
  "paper": { "stock": "ケント紙 200g", "size": "A4横" },
  "spreads": [
    {
      "id": "clock",
      "base": { "texture": "paper/kraft.png" },
      "mechanisms": [
        {
          "type": "v-fold",
          "id": "tower",
          "glueAngle": 45,          // 背に対する糊代の角度
          "height": 60,             // mm
          "faces": ["art/tower_a.png", "art/tower_b.png"],
          "sound": { "on": "open", "clip": "sfx/paper_rise.wav" }
        },
        {
          "type": "volvelle",
          "id": "clock-dial",
          "center": [120, 80], "radius": 35,
          "bind": { "target": "time.minutes" },   // 実データに結線
          "sound": { "on": "step", "clip": "sfx/click.wav", "everyDeg": 6 }
        }
      ],
      "hotspots": [ { "at": "tower", "sound": "sfx/boing.wav", "wiggle": 0.3 } ]
    }
  ]
}
```

`bind` で実データ（時刻・天気・カレンダー）に繋げられるのが「コンピュータ」たる所以。

## 4. 「紙に見せる」ためのレンダリング指針

3Dで紙を作ると、たいてい**プラスチックに見える**。対策：

- **影が主役**：AO とソフトシャドウを強めに。立体感の9割は影で出る
- **裏透け**：薄紙は光を通す。two-sided ライティング＋簡易トランスルーセンシ
- **反り**：完全な平面にしない。頂点を微小にディスプレイスして波打たせる
- **エッジ**：断面に僅かな白（紙の白い切り口）とケバ立ちノイズ
- **印刷感**：シェーダで CMYK 網点と 0.1mm の版ズレを加える
- **ライトは1灯**：机上のスタンド1つ。多灯にすると途端に嘘くさくなる
- **カメラは固定気味**：斜め上から見下ろす。マウスに数度だけ追従して「机の上にある」感

## 5. 音の設計

- BGM を置かない。**無音が基底**
- ページをめくる音は θ の**角速度**でグラニュラー合成。ゆっくり開けばゆっくり擦れる
- オブジェクトごとに固有音。近い音程で並べて、触っていると勝手に音楽になるよう調律する
- 音は必ず「触った瞬間」に鳴る。遅延ゼロ（Web Audio の事前デコード必須）

## 6. 実物への出力（ここが現代版の意味）

デジタルで作ったポップアップを **印刷して実際に組み立てられる**。

- SVG / PDF で展開図を出力
  - 実線 = カット、破線 = 山折り、点線 = 谷折り、グレー = 糊代
- Silhouette / Cricut 等のカッティングマシン用にレイヤ分け出力
- 組み立て手順を θ アニメーションから自動生成（逆再生 = 組立順）

**画面の中で作って、机の上に出てくる。** 原典が「紙をコンピュータの中に入れた」作品なら、
こちらは「コンピュータの中の紙を外に出す」作品になる。

## 7. 開発ロードマップ

### Phase 0：調査（1〜2週）
- 現物（中古CD-ROM）を入手し、エミュレーション環境で実際に触る
- 発売年と受賞歴を一次資料で確定させる（§0の「要確認」を潰す）
- 何が気持ちよかったのかを言語化してこのドキュメントを更新

### Phase 1：機構カーネル MVP（2週）
- `popup-core`：V字折り・平行折りの θ キネマティクス＋単体テスト
- ヘッドレスで展開図 SVG を1枚出す（3Dなしで検証できる状態を先に作る）

### Phase 2：ビューア（2週）
- R3F で1見開きを描画、ドラッグでページ開閉、クリックで音
- **ここで「気持ちいいか」を判定する。駄目なら Phase 1 に戻る**

### Phase 3：エディタ（4週）
- 2D型紙ビュー＋3Dプレビューの分割画面、機構の追加/編集、Validator

### Phase 4：作品「紙のデスクトップ」（4週）
- 時計・天気・音楽・カレンダーの4見開き。実データ結線

### Phase 5：実物出力（2週）
- PDF/カッティングマシン出力、組立手順の自動生成

## 8. 技術選定

| 領域 | 採用 | 理由 |
|---|---|---|
| フレームワーク | Next.js (App Router) + TS | リポジトリ名が `.next` |
| 3D | React Three Fiber + drei | 宣言的、R3F のエコシステム |
| 状態 | Zustand | θ を1箇所で持つだけなので軽量で十分 |
| 音 | Web Audio API 直叩き | 低遅延とグラニュラー合成が必要 |
| アセット | Blender → glTF | 複合機構はベイクして持ち込む |
| 型紙出力 | 自前 SVG 生成 | ライブラリ不要 |
| テスト | Vitest（`popup-core` のみ厚く） | 幾何は回帰テストが効く |

## 9. やらないことリスト（重要）

- スコア・実績・レベル・チュートリアル
- ログイン必須化、課金導線
- 物理エンジンによる紙のシミュレーション（重い・不安定・不要）
- 写実的な3D。あくまで「紙工作」の解像度に留める
- VR対応（机の上のスケール感が壊れる）

## 10. 法的整理

- 原典のアセット（絵・音・テキスト・フォント）は一切使わない
- 「ポップアップコンピューター」の名称は使わない。別名で出す
- 現物のCD-ROMを自分で買って私的に動かす／構造を調査するのは問題なし
- 影響を受けた作品として、松本弦人『Pop up Computer』（アスク講談社）へクレジットで敬意をもって言及する
